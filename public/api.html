UC Upcoming Conferences

公開API

学会の締め切り情報をJSONで取得できます。登録やAPIキーは不要で、他のサイトのJavaScriptからも直接呼び出せます。

すぐに試す

curl '{origin}/api/conferences/export?upcoming=1'

ブラウザで開く

const res = await fetch('{origin}/api/conferences/export?upcoming=1&type=international');
const conferences = await res.json();

エンドポイント

GET /api/conferences/export

パラメータはすべて省略できます。省略すると、終了した学会も含めて公開中の全件を返します。

パラメータ説明例
upcoming1 で終了した学会を除きます。終了日が未設定の学会は残ります。upcoming=1
typedomestic（国内）または international（国際）type=domestic
tagタグの完全一致。同じ学会の各回に共通のタグが付いています。tag=icml
sinceこの日時以降に更新された学会だけを返します。ISO 8601形式で、時刻を書く場合はタイムゾーンも付けてください。since=2026-11-01T00:00:00Z
fields返す項目をカンマ区切りで指定します。fields=name,website,endDate
formatjson（既定）または ndjson（1行に1件）format=ndjson

レスポンスの項目

JSONの配列で返します。日付は YYYY-MM-DD 形式で、未設定の締切や日付は null です。

項目説明
idレコードのID
name学会名
typedomestic または international
applicationDeadline申込期限
abstractDeadline抄録提出期限
manuscriptDeadline原稿提出期限
startDate / endDate開始日 / 終了日
website学会のURL（未設定なら空文字）。利用者の入力なので、リンクにするときは http / https か確認してください。
tag同じ学会の各回に共通のタグ（未設定なら空文字）
areas分野の配列（未設定なら空配列）
location開催地
isHidden非表示かどうか。公開APIでは常に false です。
createdBy / updatedBy登録・更新したユーザの内部ID（数値）
createdAt / updatedAt登録・更新日時（UTC、YYYY-MM-DD HH:MM:SS）

カレンダーで購読する

締切と開催期間を iCalendar 形式で配信しています。一覧ページの「カレンダーに追加」から登録するか、次のURLをカレンダーアプリに登録してください。

{origin}/api/conferences/calendar.ics

GET /api/conferences/calendar.ics

パラメータ説明例
typedomestic（国内）または international（国際）type=domestic
includedeadlines（締切のみ）または dates（開催期間のみ）。省略すると両方です。include=deadlines

反映のタイミングはカレンダーアプリによります。直前の締切は公式サイトで確認してください。

サイトに埋め込む

一覧ページは iframe で埋め込めます。URLのパラメータで、最初の表示状態を指定できます。

<iframe src="{origin}/?areas=機械学習,ネットワーク&theme=dark"></iframe>
パラメータ説明例
areas最初にチェックを入れる分野（カンマ区切り）。指定した分野の学会だけを表示します。分野が未設定の学会も表示するには 未設定 を含めてください。閲覧者はチェックボックスで変更できます。areas=機械学習,未設定
themelight（既定）、dark、または auto（閲覧者のOS設定に従う）theme=dark

利用時の注意

  • 応答は最大60秒キャッシュされます。短い間隔で繰り返し取得する必要はありません。
  • since では、削除や非表示になった学会を検出できません。手元のデータと同期するときは、定期的に全件を取得してください。
  • 締切は変更や延長されることがあります。投稿の前に、学会の公式サイトで確認してください。
